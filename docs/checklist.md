# Reviewer Checklist

Before approving any change in this repository, the reviewer should confirm each of the following items:

## Checklist

- [ ] Tests added or updated — new functionality is covered by tests, and existing tests are adjusted for behavior changes.
- [ ] Docs reflect the change — user-facing and internal documentation has been updated to match the current behavior.
- [ ] No new security advisories — no known vulnerabilities introduced, dependency alerts and security advisories are clean.
- [ ] CI green — the CI pipeline has run against the latest commit of the pull request and all required checks have passed.
